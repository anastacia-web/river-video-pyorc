# Open This Project in Visual Studio Code

## Easiest way

1. Extract the ZIP file.
2. Open **Visual Studio Code**.
3. Click **File > Open Folder**.
4. Select the folder **river-video-pyorc**.
5. Open `notebooks/river_analysis.ipynb`.
6. When VS Code asks for a Python kernel, select **Python (pyorc_env)**.
7. Run the notebook from the first cell downward.

## GitHub

If this folder is already a GitHub repository, use:

- **Source Control** on the left side of VS Code to commit and sync changes.
- **Git: Clone** when you want to pull/clone another GitHub repository.

If you have not created the GitHub repository yet, create it on GitHub first, then use VS Code's **Publish to GitHub** option or add the repository URL as the remote.

Do not put GitHub passwords or tokens in this folder.
